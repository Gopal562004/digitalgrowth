# 📈 DigitalGrowth

DigitalGrowth is a professional digital agency landing page designed to help businesses build an online presence, showcase services, and generate leads. It includes sections for services, featured projects, contact forms, and team highlights.

🌐 **Live Demo:** https://digitalgrowth-ecru.vercel.app

---

## 🧱 Features

- Responsive landing page design  
- Service sections (Web Development, SEO, E-commerce, Mobile Apps)  
- Featured project showcase  
- Contact & consultation section  
- SEO optimized and mobile-friendly layouts  
- Built for performance & fast loading

---

## 🛠 Tech Stack

| Technology | Purpose |
|------------|---------|
| Next.js / React | Frontend framework |
| Tailwind CSS | Styling |
| Vercel | Deployment |
| (optional) Email API | Contact form handling |
| (optional) SEO tools | Meta tags, OG previews |
